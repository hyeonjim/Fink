### 서비스 개요

현대인들의 복잡한 금융 의사결정을 돕기 위해 개발된 **AI 기반 맞춤형 금융 서비스**입니다.
사용자의 목적/자산/기간을 입력하면 목표 달성 가능성을 수학적으로 검증하고, 최적의 금융 상품(예·적금) 조합을 추천합니다. 예·적금뿐만 아니라 주식·환율·금속 시세까지 한눈에 확인할 수 있으며, AI는 증권사 커뮤니티 크롤링·뉴스·유튜브 영상을 근거로 매수·매도 판단을 돕습니다.

### 핵심 가치

| | |
|:---:|:---|
| 🎯 **목표 중심 추천** | 주거·저축·여행 등 목적에 맞는 상품 추천 |
| 🤖 **AI 분석** | GPT(`gpt-4.1-mini`) 기반 전문가 수준 분석 |

### 차별점

| | |

## 🧠 AI 추천 알고리즘 <a id="algorithm"></a>

금융 상품 추천은 **4단계 파이프라인**으로 구성됩니다.

```
1️⃣ 수학적 계산  →  2️⃣ 후보 선정  →  3️⃣ 점수 산출  →  4️⃣ GPT 분석
```

<details>
<summary><b> 단계별 상세 보기</b></summary>

<br/>

**1단계 · 목표 달성 가능성 계산** (`compute_goal_math`)

이자소득세 15.4%를 반영하여 세후 수령액을 계산하고 목표 달성 여부를 판정합니다.

```python
INTEREST_TAX_RATE = 0.154  # 이자소득세 15.4%

planned_total    = monthly_amount × period_months                              # 적금 원금
saving_interest  = monthly_amount × avg_rate × (period_months + 1) / 2 / 12     # 적금 이자(단리)
deposit_interest = current_savings × avg_rate × (period_months / 12)           # 예금 이자
total_interest   = saving_interest + deposit_interest
final_amount     = current_savings + planned_total + total_interest × (1 - 0.154)
achievable       = final_amount >= target_amount
```

**2단계 · 후보 상품 선정** (`pick_candidates_scored`)

사용자 목표 기간에 가장 가까운 상품 기간을 선택하고, 입력 조건에 따라 전략을 결정합니다.

- 월납입액 > 0 → 적금 중심 추천
- 보유금 > 0 → 예금 + 적금 조합 추천
- 둘 다 없음 → 예금 중심 추천

**3단계 · 점수 산출** (`candidate_score`)

각 후보를 5가지 요소로 점수화합니다.

| 요소 | 가중치 / 범위 |
|:---|:---|
| 달성가능성 (feasibility) | 55% |
| 금리 (0~6% 정규화) | 35% |
| 채널 가산점 (인터넷 +0.12 / 스마트폰 +0.08) | 최대 +0.17 |
| 우대조건 감점 (실적·카드 등) | 최대 -0.4 |
| 한도·기간 적합성 | -0.25 ~ +0.1 |

**4단계 · GPT 분석** (`call_gpt_json`)

선정된 상위 후보를 GPT(`gpt-4.1-mini`)에 전달하여 최종 추천을 JSON으로 받습니다.
`response_format={"type": "json_object"}`, `temperature=0.2`로 일관된 응답을 보장합니다.

```json
{
  "summary": "전체 분석 요약",
  "strategy": "추천 전략",
  "recommendations": [{ "product_id": 0, "kind": "deposit/saving", "fit_score": 0.0, "reason": "..." }],
  "alternative_suggestions": [],
  "goal_math": {},
  "combination_strategy": "예금+적금 조합 전략",
  "ai_verdict": "실행 관점 종합 조언"
}
```

</details>

## 🤖 AI 활용 <a id="genai"></a>

전 영역에서 `gpt-4.1-mini` (SSAFY GMS OpenAI 프록시 경유)를 활용합니다.

<details>
<summary><b>1. 금융 상품 추천</b> (recommendations/llm.py)</summary>

<br/>

한국 예·적금 전문 어시스턴트로 동작하며, 이자소득세 15.4%가 반영된 서버 계산을 신뢰하고 목적별 컨텍스트를 추가합니다.

- **housing** : 매매/전세/월세별 부대비용(3~5%) 안내
- **travel** : 환율 변동, 여행 일정 고려
- **savings** : 장기 자산 형성 전략, 예비비 10~20% 권장

</details>

<details>
<summary><b>2. 챗봇 의도 분류</b> (chatbot/views.py)</summary>

<br/>

사용자 질문을 **7가지 의도**로 분류하여 맞춤 응답을 생성합니다.

| # | Intent | 설명 |
|:---:|:---|:---|
| 1 | `bank_location` | 은행 위치 찾기 (카카오맵) |
| 2 | `product_search` | 금융 상품 검색 |
| 3 | `travel_budget` | 여행 예산 질문 |
| 4 | `news_search` | 뉴스 / 시사 검색 (네이버) |
| 5 | `investment_advice` | 투자 / 부동산 조언 |
| 6 | `stock_sentiment` | 특정 종목 매수 / 매도 의견 |
| 7 | `general_chat` | 일반 대화 |

출력: `{ intent, entities, confidence }`

</details>

<details>
<summary><b>3. 주식 감성 분석</b> (toss_crawler.py + GPT)</summary>

<br/>

Selenium으로 토스 증권 커뮤니티 댓글을 크롤링한 뒤 GPT로 감성을 분석합니다.

```python
crawl_result = fetch_toss_comments(stock_name, limit=20, max_scroll=5)
analysis     = analyze_stock_sentiment(comments, stock_name, client)
# → { sentiment, recommendation(buy/sell/hold), confidence,
#     positive_points, negative_points, news, youtube_videos }
```

</details>

## 💬 프로젝트 후기 <a id="review"></a>

## 박승찬 (Frontend / Backend / AI)

**잘한 점**
- GPT API를 활용한 금융 상품 추천 알고리즘 설계가 실제 전문가 수준의 분석을 제공할 수 있도록 구현됨
- 7가지 의도 분류 기반 챗봇 시스템으로 다양한 사용자 요구에 대응 가능
- 이자소득세 15.4% 등 실제 금융 규칙을 반영한 현실적인 계산 로직 구현
- 주식 커뮤니티 크롤링을 통해 AI가 주식 데이터와 더불어 판단 근거를 가져오는 로직 구현

**아쉬운 점**
- 초기 설계 시 더 많은 시간을 투자했으면 중간 수정이 줄었을 것
- DB 설계를 더 효율적으로 구현하였으면 명확한 모델 설계가 가능했을 것
- 주식 데이터를 효율적으로, 빠르게 받아오는 방법을 더 찾아보았으면 갱신 속도를 더 빠르게 가져갈 수 있었음
- 어떤 데이터를 Pinia에 저장할지 좀 더 고민했으면 더 효율적인 설계가 가능했을 것
- 실제 금융권의 이자 계산 방식·세금을 더 확실하게 알았으면 더 정확한 계산이 가능했음

**배운 점**
- Django REST Framework와 Vue.js 연동 경험
- 생성형 AI API 활용 및 프롬프트 엔지니어링
- 웹 크롤링과 데이터 처리

## 문현지 (Frontend / Backend / AI)

**잘한 점**
- 다양한 프레임워크를 시도한 점 (Canvas, Chart.js)

- 수업시간에 배우지 못한 코드들을 새로 공부하며 프로젝트에 적용함
